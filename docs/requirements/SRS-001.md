## SRS-001 — Write failure propagation

Every write operation on the audit log shall propagate OSError to the caller on failure. The logger shall use fsync() to confirm durable storage before returning. No write failure may be silently swallowed.

Acceptance-criteria:
- A disk-full condition raises OSError before the write function returns
- fsync() is called on the file descriptor after every write
- Unit test covers OSError propagation with a mock that raises on write
